Проверка, есть ли уже такой пользователь: 
GET /users/{telegram_id} - найти такого пользователя в базе данных. 
telegram_id берем из пользователя
Ответы: 
200 - ОК - такой пользователь уже есть 
404 - Not Found - Пользователь не найден

Создание/регистрация пользователя
POST/ users - создать пользователя 
передаем запрос: 
telegram_id (приходит из бота), 
name (пользователь указывает сам), 
salary_date в формате integer check (1-31)(пользователь указывает сам. Можно не указывать.)
получаем:  
telegram_id
name 
salary_date
id (сгенерированный serial PK)
ответы: 
201 - Created - пользователь создан 
400 - Bad Request - переданы некорректные данные типа дата не в диапазоне 1-31 

Выбрать категорию
GET /categories
Query-параметры: 
?side=spend - показать список категорий с расходами (всего 6). 
?side=income - показать список категорий с доходами
Ответы: 
200 ОК - показать список всех категорий с расходами 

Создать транзакцию пользователя 
POST /transactions - создать транзакцию в базе данных
Передаем: 
user_id - сгенерирован автоматически при регистрации пользователя 
date - дата операции в формате YYYY-MM-DD
sum - cумма операции в формате numeric.
category_id - категория в формате числа (получено от фронта на эндпоинте GET /categories) 
side - выбрал пользователь на предыдущем шаге
Получаем: 
id (сгенерирован при создании транзакции)
side
category_name
sum
date
Ответы:  
201 - Created - успешно созданы 
400 - Bad Request - невалидные данные 
404 - Not Found - пользователь не найден 

Удалить транзакцию
DELETE /transactions/{id} - удалить конкретную транзакцию по ее id
передаем:  
user_id
получаем: 
пустое тело
ответы: 
204 - No Content - пусто 
400 - Bad Request - невалидные данные (id не в том формате, например)
404 - Not Found - не найден такой user_id, id транзакции. 

Изменить транзакцию
PATCH /transactions/{id}
передаем поля, которые разрешаем изменять: 
user_id
sum - сумма транзакции 
category_id - категория транзакции 
date - дата транзакции 
возвращается: 
user_id
id транзакции 
sum 
category_id
date
ответы: 
200 - ок - все успешно 
400 - Bad Request невалидные данные 
404 - Not Found - не найдена такая транзакция или пользователь.
